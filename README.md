### SISTEM REKOMENDASI PROGRAM LATIHAN KEBUGARAN TERPERSONALISASI BERBASIS WEB MENGGUNAKAN WEIGHTED CONTENT-BASED FILTERING DAN WEIGHTED COSINE SIMILARITY 
STUDI KASUS: BIJE’S GYM

#

### Fokus Penelitian
Penelitian berfokus ke implementasi dan evaluasi Content-Based Filtering menggunakan Weighted Cosine Similarity untuk menghasilkan rekomendasi program latihan kebugaran berdasarkan profil anggota Bije’s Gym. Website adalah media implementasi dan eksperimen, sedangkan fokus utama penelitian adalah kinerja dan kualitas metode rekomendasi.

### Bidang Fokus
Sistem Cerdas & Rekayasa Perangkat Lunak (Intelligence Systems & Software Engineering)

### Topik Penelitian
Sistem Rekomendasi (Recommender Systems)

### Metode / Algoritma
Content-Based Filtering (CBF) dengan Weighted Cosine Similarity

### Metode pengembangan
Rapid Application Development (RAD)

### Domain
Kesehatan & Kebugaran (Health & Fitness) — Bije's Gym

### Teknologi
- Frontend: HTML, CSS, JavaScript
- Backend: Python 3 & Flask
- Database & Management: MySQL 8.0 & phpMyAdmin
- Data Processing: Python
- Tools Pengembangan: VS Code, GitHub, MAMP

### Objektif Utama
- Mengimplementasikan Content-Based Filtering untuk menghasilkan rekomendasi program latihan berdasarkan profil anggota.
- Menerapkan Weighted Cosine Similarity untuk mengukur kemiripan profil anggota dan program latihan.
- Mengevaluasi kualitas rekomendasi yang dihasilkan.
- Membandingkan Weighted Cosine Similarity dengan Cosine Similarity tanpa pembobotan.
- Menganalisis pengaruh bobot fitur terhadap hasil dan ranking rekomendasi.
